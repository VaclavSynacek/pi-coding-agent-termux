# pi-coding-agent-termux

**⚠️ DEPRECATED**

This Termux port is no longer needed. **Upstream pi now supports Termux directly since v0.51.0.**

Please uninstall this port and use the official upstream package instead:

```bash
npm uninstall -g @vaclav-synacek/pi-coding-agent-termux
npm install -g @mariozechner/pi-coding-agent
```

For documentation, see the [upstream pi-coding-agent README](https://github.com/badlogic/pi-mono/tree/main/packages/coding-agent).

---

**Why this change?**

The upstream project has integrated Termux support directly, making this port redundant. 

**Last port version:** v0.51.1-2 instructs to upgrade to upstream

**Upstream repository:** https://github.com/badlogic/pi-mono
